# Sorting-ALGOrithms
📊 Sorting Algorithms Repository

This repository contains implementations of fundamental sorting algorithms written in a clean, structured, and beginner-friendly manner. It is ideal for understanding core concepts of Data Structures and Algorithms (DSA).

🚀 Algorithms Included
🔹 Bubble Sort
🔹 Selection Sort
🔹 Insertion Sort
🔹 Merge Sort
🔹 Quick Sort

📌 Features
Simple and easy-to-understand code
Well-structured implementations
Helpful for beginners and students
Covers both basic and advanced sorting techniques
Useful for coding interviews and exam preparation
